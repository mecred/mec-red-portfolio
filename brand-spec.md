# Diastema Dental Clinic — Brand Spec

Extraite des captures Instagram de la clinique et du positionnement « éditorial & luxe » choisi par le client.

## Palette

```css
:root {
  --bg:      oklch(97% 0.008 80);   /* ivoire chaud, papier-texturé */
  --surface: oklch(100% 0 0);       /* blanc pur pour cartes */
  --fg:      oklch(18% 0.02 45);    /* brun-charbon profond */
  --muted:   oklch(45% 0.025 65);   /* terre cuite atténuée */
  --border:  oklch(88% 0.012 70);   /* beige doux */
  --accent:  oklch(55% 0.14 40);    /* terracotta — signature, utilisée max 2× par écran */
  --accent2: oklch(52% 0.06 200);   /* vert sauge discret (médical / confiance) */
}
```

## Typographie

- **Display (titres, hero)** : `'Iowan Old Style', 'Charter', Georgia, serif` — associé Editorial-Luxe
- **Body** : `-apple-system, BlinkMacSystemFont, 'Segoe UI', system-ui, sans-serif` — lisible, sobre
- **Mono (métadonnées)** : `ui-monospace, 'SF Mono', Menlo, monospace`

## Posture

- Serif display généreux (clamp 36–72 px), body sans-serif
- Marges amples, rythme éditorial (pas de cartes surchargées)
- Accent terracotta utilisé **max 2× par écran** (CTA + logo) — le reste en muted/fg
- Photos clinical / before-after en pleine largeur, recadrées franches
- Galerie avant/après en paires côte-à-côte avec diviseur central
- Élégance méditerranéenne — chaleureux, pas clinique froid
- **Anti-emoji** : témoignages en typographie pure, pas d'icônes Unicode

## Layout

- En-tête sticky avec logo + nav, fond transparent → blanc au scroll
- Sections amples, 80–140 ch max-width centré
- Services : grille 3 colonnes + 1 carte vedette pleine largeur (image + texte)
- Blog : 1 article vedette (image + texte) + grille 2 colonnes
- Galerie : paires avant/après en side-by-side avec diviseur vertical
- Footer sombre avec coordonnées, horaires, réseaux
- Carte interactive Google Maps en plein large sous le formulaire
